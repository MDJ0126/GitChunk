Git Chunk / Large file versioning

큰 파일도,
하나의 Git 저장소에서.

원본 파일로 평소처럼 작업하세요. Git Chunk가 큰 파일을 자동으로 나누어 코드와 같은 Git 저장소에 보관하고, 체크아웃할 때 원본으로 복원합니다.

Windows용 다운로드x64
macOS: Apple Silicon·Intel
작동 방식과 설치 알아보기 →

시작하기

1

Git Chunk 설치

Windows는 릴리스의 설치 파일을 실행하거나 Scoop으로 설치하세요.

scoop bucket add gitchunk https://github.com/MDJ0126/GitChunk.git
scoop install gitchunk/git-chunk

macOS에서는 Homebrew를 사용하세요.

brew tap MDJ0126/gitchunk https://github.com/MDJ0126/GitChunk
brew install --cask MDJ0126/gitchunk/git-chunk
2

프로젝트에 한 번 적용

프로젝트의 Git 저장소 최상위 폴더에서 실행하세요. 앱에서 프로젝트를 선택하고 Install Git Chunk를 눌러도 됩니다.

git chunk install

이미 추적 중인 파일이 있다면 다음 명령으로 저장 방식을 적용하고 커밋하세요.

git add -u
git add --renormalize .
git add .gitattributes .gitignore .gitchunk
git commit -m "Configure Git Chunk"
3

이제 평소처럼 작업하세요

이미지·영상·게임 리소스를 원래 프로그램으로 편집하고, 평소처럼 커밋·푸시·풀하시면 됩니다.

git add .
git commit -m "Update assets"
git push

새 PC에서 클론한 후에도 git chunk install을 한 번 실행하세요. 함께 작업하는 분들도 각자 설치하고 프로젝트에 적용해야 합니다.

알아두면 좋은 점

저장은 청크로, 작업은 원본으로

기본 설정에서는 50 MiB를 초과하는 파일을 최대 49 MiB 청크로 나눕니다. 작업 폴더에서는 원본 파일을 사용합니다.

기존 Git 저장소 사용

코드와 청크가 같은 Git 저장소에 보관됩니다. 파일을 나누어도 전체 용량은 줄지 않으며, 호스팅 서비스의 용량 제한이 적용됩니다.

필요한 파일만 제외

프로젝트의 .chunkignore에서 분할하지 않을 경로를 지정할 수 있습니다. 제외한 파일도 Git으로 추적됩니다.

기존 LFS 프로젝트 전환

설치 시 현재 LFS 파일의 전환을 지원합니다. 과거 LFS 데이터와 사용 용량은 자동으로 삭제되지 않습니다.

더 자세한 사용법

업데이트, LFS 전환, 제외 규칙, 제거 방법은 상세 가이드에서 확인하세요.
