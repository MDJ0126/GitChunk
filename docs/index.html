Getting started

1

Install Git Chunk

On Windows, run the installer from Releases, or install with Scoop.

scoop bucket add gitchunk https://github.com/MDJ0126/GitChunk.git
scoop install gitchunk/git-chunk

On macOS, use Homebrew.

brew tap MDJ0126/gitchunk https://github.com/MDJ0126/GitChunk
brew install --cask MDJ0126/gitchunk/git-chunk
2

Set up your project once

Run this in the root of your Git repository. Or select your project in the app and click Install Git Chunk.

git chunk install

For files already tracked by Git, apply the storage method and commit the configuration.

git add -u
git add --renormalize .
git add .gitattributes .gitignore .gitchunk
git commit -m "Configure Git Chunk"
3

Work as usual

Edit images, videos, and game assets in your usual programs. Then commit, push, and pull as you normally would.

git add .
git commit -m "Update assets"
git push

Run git chunk install once after cloning on a new computer. Each collaborator also needs to install Git Chunk and set up the project.

Good to know

Chunks in storage. Originals at work.

By default, files over 50 MiB are split into chunks of up to 49 MiB. Your working directory contains the original files.

Your existing Git repository

Code and file chunks live together. Splitting does not reduce total size; your Git host’s storage limits still apply.

Exclude selected paths

Use .chunkignore to keep matching files whole. Excluded files are still tracked by Git.

Moving from Git LFS

Installation supports converting current LFS files. Historical LFS data and its storage usage are preserved.
