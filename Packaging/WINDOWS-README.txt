Git Chunk for Windows — normal command-line package

Recommended: use GitChunk-Setup-win-x64.exe to install the command and add it to PATH.
For portable use, keep this folder in a permanent location and add it to PATH.
Open a new terminal, then run inside each repository:

  git chunk install
  git chunk status

No executable is copied into your repositories.
The optional graphical diagnostic tool is a separate download:
GitChunk-Debug-Windows-x64.zip
